# Tessera 品牌素材

- `tessera-icon.svg`：应用图标母版（亚麻色圆角底 + 瓷砖拼成的 T，最后一块陶土色略歪）。
- `tessera-mark.svg`：只含瓷砖的标志，用于界面内（`BrandMark` 组件的图形与它一致）。
- 仓库根目录的 `logo.ico` 由图标母版生成，含 16 / 24 / 32 / 48 / 64 / 128 / 256 像素；16 到 32 像素使用更大的方块和零倾斜，保证小尺寸清晰。

颜色：松林绿 `#2F6B5E` `#4E9484` `#1F4A41` `#3A7A6A`，陶土 `#D9774A`，亚麻 `#EFE8D8`。
